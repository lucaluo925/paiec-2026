## 机制假设

在**未见 benchmark 内部**，`item_content` 的文本相似关系与基线预测残差相关：
相似文本的题目，基线预测偏高或偏低的方向一致。若成立，则可以用预算内已获标签题目的残差，
推断同 benchmark 内目标题目的残差——**不需要题目难度系数跨 benchmark 迁移**，
这正是它与发现 6 的关键区别。

**新增的、未经验证的假设**：文本相似性↔基线残差的相关关系在未见 benchmark 内仍成立。
实测的官方 embedding 跨 benchmark 迁移 r≈0 并未证明本假设为真或为假（那测的是难度系数迁移，
不是 benchmark 内的残差传播）；固定的 n-gram 表示甚至可能比 embedding 更弱。

## 实现约束（与提交环境一致）

- 仅 numpy + 标准库；无网络、无 API；
- 固定的词 + 字符 n-gram 文本表示，固定形式的相似度核；
- 在现有预测的 logit 上加一个**零均值**的文本残差项；
- 核强度只在**训练 benchmark** 上估计，**不做验证集搜索**；
- 当前 benchmark 无任何标签时，修正**严格为零**（B0 必须逐位不变）。

## 固定设计

| 项目 | 设计 |
|---|---|
| 比较 | 冻结基线 vs 基线＋文本残差核 |
| 验证 | 四个 benchmark 的 LOBO；所有参数仅用另外三个折拟合 |
| 标签 | 与基线**完全相同**的随机 acquisition 轨迹与预算（同 seed） |
| 跨 subject 证据 | 按**实际运行可见的 cohort 规模**回放，不得把整个公开 benchmark 的全部 subject 同时供给预测器 |
| No-op 控制 | 固定打乱支持题目的文本归属，保留 subject、标签、预算、基线处理不变 |
| 主统计量 | 官方 pair 等权 ΔALC = A_base − A_candidate（正数=变好） |

## 通过门槛（四条全中才算通过）

1. **ΔALC ≥ 0.045**（本地 0.16515 → ≤ 0.12015）
2. 三个含多个 pair 的 fold **全部**改善
3. 单 pair fold（`swe_rebench`）退化 **≤ 0.005**
4. 打乱文本的 no-op 控制相对基线，**|ΔALC| ≤ 0.002**

**任一不满足 → 否证"该机制足以支持冲向 0.117 的新提交"，停手，不得事后降低门槛。**
若收益落在 0.005 量级，如实写进报告，但**不构成更换冻结提交的理由**。

## 事前声明的已知虚高风险

- 公开 benchmark 有很多 subject，而线上 formative 每次总共只有 8–9 个 pair。
  跨 subject 的在线学习若在本地拿到远多于运行环境的标签，收益会被高估——
  故设计里强制按实际 cohort 规模回放。
- 四个 LOBO fold 实际只有约三个有充分信息的泛化单位；
  **不得**用 19,621 个 target 的窄置信区间去论证新 benchmark 上的收益。

## 读数

1. **效应是真的，但量级错了两个数量级。** 打乱文本的控制给出 0.00000，而真实文本给出
   +0.00052，说明这 0.0005 确实来自文本关系而不是噪声——控制组干净得近乎完美。
   但门槛要的是 0.045。这正是外审事前预计的"0.005 量级"，实测还更低一档。
2. **B0 四折全部逐位相同**，"无标签时修正严格为零"的设计性质成立。
3. **fold 3 的 lam = 0.00000**：那一折的三个训练 benchmark 里没有可用的文本↔残差关系，
   方法自己拒绝施加修正。这是设计意图（无证据不行动），但也说明机制**跨 benchmark 不稳**。
4. **伤害集中在单 pair 折**：swe_rebench 退化 0.0105，是四折里唯一变差的，也恰是
   v0 那支 `heterogeneity.py` 实验预警的形态——"在多数 benchmark 上有用、在某一个上有害"。
   一个 pair 的折本来就不稳，但门槛是事前写死的，不能因为样本小就豁免。
5. **一条实现层面的发现**：曾把 HASH_DIM 从 4096 降到 512 省算力，训练集上估出的
   lam 从 0.392 掉到 0.054。**哈希宽度不是中性的实现常数**，窄哈希会把文本信号压掉。
   已改回 4096，改用缩小 cohort 控制算力——而缩小 cohort 本来就是预注册要求的。
